Open-source orchestration framework for AI agent development, combining marketplace-style tooling, async skill installation, and a structured multi-phase workflow for building and running agents.

This project is centered on making agent development more modular and operationally practical. It brings together task coordination, tool installation, and workflow structure in a way that supports repeatable experimentation.
